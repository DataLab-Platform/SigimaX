The `sigimax` package requires the following Python modules:

.. list-table::
    :header-rows: 1
    :align: left

    * - Name
      - Version
      - Summary
    * - Python
      - >=3.9, <4
      - Python programming language
    * - PlotPy
      - >= 2.7.4
      - Curve and image plotting tools for Python/Qt applications
    * - psutil
      - >= 5.7
      - Cross-platform lib for process and system monitoring.
